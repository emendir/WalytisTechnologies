# Walytis Networking

The networking module uses an identity's encryption and authentication capabilities to securely share the blocks produced by the Walytis Database Blockchain with other peers defined by the identity.
It also provides communication channels of [Strong Protection](../../2.%20Endra%20Stack%20Integration%20Architecture/Security%20Model/6.%20Protection%20Levels.md#Strong%20Protection) for securely sharing data of [Confidentiality Level Secret](../../2.%20Endra%20Stack%20Integration%20Architecture/Security%20Model/5.%20Confidentiality%20Classification.md#Secret), such as private keys.

## Guarantees

Blocks WILL be shared only with the defined set of peers with at least [Standard Protection](../../2.%20Endra%20Stack%20Integration%20Architecture/Security%20Model/6.%20Protection%20Levels.md#Standard%20Protection).

Transports for sharing information of [Convfidentiality Level Secret](../../2.%20Endra%20Stack%20Integration%20Architecture/Security%20Model/5.%20Confidentiality%20Classification.md#Secret) WILL provide [Strong Protection](../../2.%20Endra%20Stack%20Integration%20Architecture/Security%20Model/6.%20Protection%20Levels.md#Strong%20Protection).

A received block WILL NOT be shared before it has been processed by the blockchain and the identity manager, the latter having had the chance to update the sharing module's access lists.
