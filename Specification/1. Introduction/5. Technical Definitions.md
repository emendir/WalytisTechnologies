# Technical Definitions

- **network**: A system of _peers_ that are able to communicate with one another.
- **peer**: An entity that participates in a _network_ by communicating with other _peers_.
- **database**: A system into which data can be stored and from which data can be retrieved.
- **blockchain**: A _database_ that may be hosted by multiple _peers_, to which identifiable units of data called _blocks_ may be appended but whose _blocks_ cannot be modified or removed, and in which each new _block_ contains a reference to one or more older _blocks_, thereby establishing a history of _blocks_.
- **block**: A unit of data stored on a _blockchain_.
- **block parents**: The set of older _blocks_ directly referenced by a _block_.
- **block ancestry**: The set of all _blocks_ that are enumerated by recursively following a _block_'s _block parents_.
- **cousin blocks**: _Blocks_ that are not ancestors of each other.
- **sibling blocks**: _Blocks_ with the exact same set of parents. This is a subset of _cousin blocks_.
- **leaf blocks**: _Blocks_ that are not known to have any children at a given point in time.
- **identity**: A persistent entity that can be authenticated cryptographically.
- **credential**: Secret cryptographic keys that can be used to authenticate an _identity_.
- **controller**: An entity that holds _credentials_ needed to authenticate an _identity_.
