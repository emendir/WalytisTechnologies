# Network Requirements

## Network Protocols

##### Requirements

The underlying network MUST provide IP connectivity using at least one supported IP version.

The network environment MUST permit the network protocols and ports required by the underlying peer-to-peer transport.

## Connectivity

##### Limitations

Not all peers are online at all times.

For any given pair of peers, it is not guaranteed that they will ever be online simultaneously.

For any given pair of peers $A$ and $Z$, there will often be a chain of asynchronous peer connections between them. For example, $A$ connecting to $B$, $B$ later connecting to $C$ and $C$ later connecting to $Z$ constitutes such a chain of asynchronous peer connections.

It is assumed that network connections might terminate at any time.

The underlying network MAY lose, duplicate, reorder, delay, or corrupt transmitted data.

## Network Security

##### Limitations

The underlying network is not considered confidential or authentic.

Outside observers might observe network-level information.

Unauthorised nodes might attempt to connect to and communicate with network endpoints.

## NAT and Addressability

##### Limitations

The IP network endpoint provided might operate behind:

- NAT
- carrier-grade NAT
- stateful firewalls
- dynamically assigned IP addresses
- changing network interfaces
- other mechanisms that prevent stable inbound connectivity
