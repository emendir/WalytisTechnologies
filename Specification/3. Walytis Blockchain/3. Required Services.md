# Required Services

## Networking

Since Walytis does not itself provide peer-to-peer communications, it must be used in conjunction with a system that provides this functionality and manages block sharing among peers.
Because Walytis doesn't sit on top that other system, it doesn't have 

### Interface

Walytis provides an interface to be used by the networking system, specified at [Interface](2.%20Provided%20Services.md#Interface).

### Requirements

When a peer creates a new block, it should be delivered to all other peers as soon as is feasible.
