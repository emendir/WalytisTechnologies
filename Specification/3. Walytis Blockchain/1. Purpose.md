In peer-to-peer networks, sharing a mutable state without a centralised source of authority is a major challenge.
Walytis provides a solution to this problem with eventually-consistent distributed databases that allow any peer to add to the data at any time, propagating that data to all peers, ensuring no data is ever lost or tampered with.

As an append-only distributed database, Walytis serves merely as a foundation for mutable shared state in peer-to-peer networks.
It is best understood as providing a shared history rather than a shared mutable state.
Most applications will build shared mutable state on top of that shared history using abstracted overlays such as:
- [WalytisIdentities](../4.%20WalytisIdentities%20-%20Identity%20Management/1.%20Purpose.md) for authentication and access-control
- [WalytisOffchain](../8.%20WalytisOffcahin%20-%20Offchain%20Encrypted%20Content/1.%20Purpose.md) for securing highly confidential data
- [WalytisMutability](../9.%20WalytisMutability%20-%20Versioned%20Content%20Mutability/1.%20Purpose.md) for version-controlled mutability
