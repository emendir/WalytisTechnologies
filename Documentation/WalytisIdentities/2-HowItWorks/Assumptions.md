- Public keys might be cracked after a long amount of time.
- Any cryptographic algorithm might be cracked, leaving all public keys for that algorithms immediately vulnerable to being cracked.
- The network traffic may always be read by malicious actors.
- Malicious actors may write on the network at the following layers:
	- write messages on IPFS pubsub
	- make requests to IPFS-TK listeners
	- write to any Walytis database
